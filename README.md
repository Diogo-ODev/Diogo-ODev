## 🛠️ Projetos

### 🏋️ Plataforma para Personal Trainers

Projeto acadêmico desenvolvido com o objetivo de criar uma plataforma para gerenciamento de personal trainers e seus alunos.

**Principais funcionalidades planejadas:**

* 👤 Cadastro de personal trainers
* 🔐 Sistema de login
* 🧑‍🤝‍🧑 Cadastro e gerenciamento de alunos
* 📝 Criação e edição de treinos
* 📊 Registro de evolução dos alunos
* ⚖️ Controle de peso e evolução
* 📅 Agendamento de aulas
* 💰 Controle financeiro
* 📖 Histórico de treinos

**Tecnologias:**

`Node.js` `Express` `Prisma` `PostgreSQL`
